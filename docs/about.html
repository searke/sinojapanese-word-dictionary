About & credits

漢語の森 lets you wander through Sino-Japanese vocabulary one kanji at a time. Every page is generated by a small script from freely licensed dictionary data; the code is on GitHub.

Dictionary data

This site uses the JMdict (Japanese–English dictionary) and KANJIDIC2 (kanji dictionary) files. These files are the property of the Electronic Dictionary Research and Development Group, and are used in conformance with the Group's licence, which is the Creative Commons Attribution-ShareAlike 4.0 licence.

The files were read through the JSON editions made by jmdict-simplified (same licence).

What was changed

Only two-kanji words from JMdict's common-word subset are shown, and only those whose reading splits into on'yomi. Glosses are shortened to the first few senses. Difficulty levels, neighbourhoods and the map are worked out by this site and are not part of the original data.

Because it is built from CC BY-SA material, the content of this site (the generated pages and graph.json) is shared under the same CC BY-SA 4.0 licence. The code that builds it is under the MIT licence; see the repository's LICENSE files.

Links out

Words link to Jisho (including its example sentences, which come from the Tatoeba project) and to Wiktionary. These are separate sites with their own terms.
